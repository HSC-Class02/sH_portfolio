# 김송현 포트폴리오

**전공에서 시작한 배움 → AI로 만든 결과물 → 책임 있는 AI 활용 → 활동 속 적용과 회고**

## 01 · About — 배움의 출발점
한림성심대학교 치위생과 김송현입니다. 전공에서 배운 것과 AI를 활용해 만들어 본 결과물을 이곳에 정리합니다. 학력 기간은 이력서 기준 2026–2029입니다.

## 02 · AI-Generated Reports — 배움을 결과물로
첫 프로젝트는 [SK하이닉스 기업분석](https://github.com/HSC-Class02/SH_SKhynix)입니다. AI 자동화로 기업 정보를 정리하고 분석 보고서로 만든 사례입니다. 후속 프로젝트는 분석 질문 → 활용 자료와 자동화 과정 → 결과물 → 검토 및 개선점 순서로 기록합니다.

## 03 · Qualifications & Certifications — AI를 책임 있게 사용하는 법
### Certificate
UNESCO · Coursera의 **Global MOOC on the Ethics of AI** 과정을 2026년 9월 20일에 수료했습니다. 앞 섹션이 AI로 무엇을 만들었는지 보여준다면, 이 섹션은 AI를 사용할 때 무엇을 고려해야 하는지 배운 기록입니다.

## 04 · Activities — 배움을 활동으로 이어가기
교내외 활동과 공모전은 참여 목적 → 맡은 역할 → 수행 내용 → 배운 점 순서로 기록할 예정입니다. 아직 등록된 활동은 없습니다.
